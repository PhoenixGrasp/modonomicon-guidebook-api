# Modonomicon — Guidebook Framework API

[![Download Latest](https://img.shields.io/github/v/release/PhoenixGrasp/modonomicon-guidebook-api?style=flat-square&label=Download&color=brightgreen)](https://github.com/PhoenixGrasp/modonomicon-guidebook-api/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A powerful in-game guidebook framework for Minecraft mods with rich formatting and advancement gating.

![Modonomicon — Guidebook Framework API Preview](https://cdn.modrinth.com/data/692GClaE/images/71d1864443c1b5dc8456b5a1b0489595099854fc_350.webp)

## Features

- Rich text formatting with images and recipe displays
- Advancement-gated entries reveal content on unlock
- Multi-book support for complex mod documentation
- Data-driven content via JSON book definitions
- Used by Occultism, Ars Nouveau add-ons, and more

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
